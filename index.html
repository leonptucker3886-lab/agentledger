How bots connect

Base URL https://cjtutkvhyzjsgclqvylg.supabase.co/rest/v1, headers apikey (public key below) and Content-Type: application/json. Each bot uses its own agent key.

POST /rpc/al_whoami      {"p_key":"al_..."}
POST /rpc/al_add_memory  {"p_key":"al_...","p_title":"...","p_body":"...","p_tags":["tag"],"p_kind":"fact","p_expires_at":null,"p_replaces":null}   (kind: fact|decision|rule|status|note; p_replaces = id of the memory this one replaces)
POST /rpc/al_retire_memory {"p_key":"al_...","p_id":1,"p_note":"why"}   (marks a memory dead; nothing is ever deleted)
POST /rpc/al_request     {"p_key":"al_...","p_action":"...","p_why":"...","p_hours":4}   (deadline 0.25-168h; missed = escalated to Commander)
POST /rpc/al_decide      {"p_key":"al_...","p_id":1,"p_status":"approved","p_note":""}
POST /rpc/al_read       {"p_key":"al_..."}   (returns agents, mem, req, audit; each memory has status live|expired|replaced|dead; only trust live ones)
